# 🏠 HomeVault

**A modern platform for managing and organizing your home inventory.**

HomeVault is a web application designed to help users organize, manage, and keep track of their home-related products and belongings.

## ✨ Features

- User authentication and account management
- Dashboard for managing home inventory
- Add and manage products
- Organized product information
- Responsive user interface

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/DAKSHYADAV512/Homevault.git
```

### 2. Navigate to the project

```bash
cd Homevault
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Visit the local URL displayed in your terminal.
